# Language Translator Web Application

## Project Description
This project is a simple Language Translator Web Application developed using HTML, CSS, and JavaScript. The application allows users to enter text, choose source and target languages, and translate the text using a Translation API.

## Features
- User-friendly interface
- Translate text between multiple languages
- Select source and target languages
- Display translated text instantly
- Copy translated text feature
- Text-to-speech feature

## Technologies Used
- HTML
- CSS
- JavaScript
- Translation API (MyMemory Translation API)

## How to Run the Project

### Step 1: Download or Clone the Project
Download the project folder or clone it using Git.

### Step 2: Open in VS Code
Open the project folder in Visual Studio Code.

### Step 3: Install Live Server Extension
Install the Live Server extension in VS Code.

### Step 4: Run the Project
- Right click on `index.html`
- Select `Open with Live Server`

The project will open in your browser.

## How the Project Works
1. User enters text in the input box.
2. User selects source language.
3. User selects target language.
4. User clicks the Translate button.
5. The application sends the text to the Translation API.
6. API returns translated text.
7. The translated text is displayed on the screen.
